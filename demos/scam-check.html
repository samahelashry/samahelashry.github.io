    How it works

    What it checks

    • Requests for codes, passwords or card details
    • Pressure to act fast or threats of blocking
    • Small fees, prizes and easy money
    • Shortened links, odd domain endings and look-alike domains
    • Moves to Telegram or a private WhatsApp

    Built security-first

    Every rule runs in the browser, so a message with personal details never reaches a server. Each red flag adds points, and the verdict explains exactly which words triggered it.

    • JavaScript
    • Regex
    • Unicode (EN · FR · AR)
