How the real version works

In this demo the replies run in your browser. In production, the same conversation runs on the restaurant's WhatsApp number.

  1. Guest writeson the restaurant's WhatsApp Business number
  2. WebhookWhatsApp Business API sends the message to a Python server
  3. AI understandsOpenAI reads the request and picks the answer or the next booking step
  4. Booking savedin Google Sheets, and the team gets a notification
