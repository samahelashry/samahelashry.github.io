## How it's built

- Plain HTML, CSS and JavaScript: no framework, no build step, each demo is one self-contained file.
- Portfolio in English and French, with light and dark themes.
- Accessible markup, responsive down to phone width.
- Privacy by default: nothing typed into the demos leaves the browser.

## Run it locally

```bash
git clone https://github.com/samahelashry/samahelashry.github.io.git
cd samahelashry.github.io
python3 -m http.server 8000
# then open http://localhost:8000
```
